# Обработка заказов службы доставки

Консольное приложение на чистом C — курсовой проект по программированию (СевГУ, 1-й курс).

Программа ведёт таблицу заказов службы доставки еды: хранит их в двусвязном списке,
умеет добавлять, редактировать, удалять, сортировать и искать записи, сохраняет данные
в текстовый и бинарный файлы и строит итоговый отчёт по каждому ресторану.

## Возможности

- **Двусвязный список** заказов с динамическим выделением памяти
- **CRUD:** создание таблицы, добавление, корректировка и удаление записи по номеру заказа
- **Сортировка** по номеру заказа по возрастанию и убыванию
- **Поиск** по неключевому полю — названию ресторана
- **Файлы:** сохранение и загрузка в текстовом (`.txt`) и бинарном (`.bin` / `.dat`) формате
- **Обработка данных:** для каждого ресторана — ТОП-5 самых щедрых заказов
  (процент чаевых от суммы) и ТОП-5 самых долгих (готовка + доставка), с записью отчёта в файл
- **Интерфейс:** меню со стрелками, постраничный просмотр таблицы (←/→), выход по Esc
  из любого ввода, проверка корректности данных и уникальности номера заказа

## Меню

```
1. Начальное создание таблицы
2. Просмотр таблицы
3. Добавление новой записи
4. Удаление записи по ключу (номер заказа)
5. Корректировка записи по ключу
6. Сортировка таблицы по ключу (возр./убыв.)
7. Поиск записи по неключевому полю (ресторан)
8. Сохранение таблицы в текстовый и бинарный файл
9. Чтение данных из текстового или бинарного файла
10. Обработка и сохранение результатов в файл
0. Выход
```

## Формат данных

Одна запись — одна строка, поля через `;`:

```
номер;ресторан;адрес;сумма_заказа;стоимость_доставки;время_готовки;время_доставки;чаевые
101;KFC;Lenina10;890;120;18;15;80
```

Тестовые данные — в [`orders_test.txt`](orders_test.txt) и [`orders_test.bin`](orders_test.bin)
(25 заказов из 5 ресторанов).

## Сборка и запуск

Программа написана под Windows (используются `conio.h` и `windows.h`).

```bash
gcc -Wall -o delivery_orders.exe main.c
delivery_orders.exe
```

Проверено с MinGW GCC 13.2.
